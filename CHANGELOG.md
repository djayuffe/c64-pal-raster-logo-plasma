# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-09-27

First complete public release.

- Verified PAL C64 PRG built with ACME strict segments.
- Corrected sprite phase indexing, logo colour-pointer handling, and
  raster-bar carry handling.
- Made the colour-wave glyph field visible in the live runtime.
- Added six direct VICE runtime captures and reproducible capture commands.
- Added GPL-3.0-only attribution for Ulf Bertilsson, integrity checksums,
  expanded documentation, and GitHub Actions build/release validation.
